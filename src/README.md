# Application Workspace

This folder is reserved for future Veylo (Velocity Flow) application source. The team has not selected a stack, and no application code, dependencies, runtime configuration, or generated artifacts have been added.

PA2 requires Spec Kit artifacts inside this folder. Initialize the agreed integration here when that work begins, verify the generated paths, and retain one Git repository at the project root. Do not create `src/.git`.

Until the stack is selected, there is no install, run, build, or test command for the application.
