# AI Usage Logs

This index collects AI usage logs by assignment. [PA1/AI_LOG.md](PA1/AI_LOG.md) preserves the historical root log.

New task records belong in `<phase>/<github-handle>.md`, for example `PA2/DankDaPancake.md`. Use the actual phase (PA2, PA3, or a named milestone) and the requesting member's handle. The handle identifies the task owner, not a claim that the member independently authored AI output. Do not create activity for other members. If ownership is unknown, use `<phase>/unassigned.md` and state the limitation.

Append one entry per task; related calls may share an entry. Each contributor edits their own file to reduce merge conflicts. Multiple agents working for the same member must coordinate append operations. Preserve append-only history and correct mistakes with amendments.

Copy [the template](TEMPLATE.md) for each new task. Record the actual date, tool/model when known, faithful prompt reference, purpose, AI work, affected files, commands/results, human validation when it happens, approvals, and limitations. Keep secrets and sensitive data out. A summary does not replace original prompt evidence required by the course.
