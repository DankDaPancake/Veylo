# PA1 Documentation

This directory contains PA1 documents and places for the team to add missing information. A template or pending field is not a completed deliverable, team agreement, or evidence of real work.

## Documents

- [Project proposal](requirements/project-proposal.md): existing scope text under the Veylo name; review and attribution remain pending.
- [Existing-app survey](requirements/existing-app-survey.md): add the team's actual two-app report, screenshots, and comparison.
- [Team contract](management/team-contract.md): fill in and acknowledge actual agreements.
- [Tools and process](management/tools-and-process.md): verified repository setup and blank fields for other tools/evidence.
- [Weekly report](management/weekly-report.md): blank planning, two Scrum meetings, and review/retrospective sections.
- [AI usage declaration](management/ai-usage.md): complete the team declaration using the actual [root AI log](../AI_LOG.md).
- [Submission checklist](management/submission-checklist.md): remaining checks and packaging.

## Completing the Submission

Use English Markdown and actual performer/reviewer/editor attribution immediately after report section headings. Add real screenshots with captions beside the relevant report or in an evidence subfolder, and link them using relative paths. Export matching PDFs only after review, rendering Mermaid where appropriate. No final PDFs or invented evidence are supplied by these templates.

Original course handouts, broader research, obsolete exports, and older setup notes stay local and ignored. Published documents do not require those ignored paths. Empty analysis-and-design/test folders retain the course-suggested structure without claiming deliverables.
